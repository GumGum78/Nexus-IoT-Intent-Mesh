# Nexus-IoT-Intent-Mesh
new IoT communication concept
The principle:
Each object publishes its capabilities and constraints.
Objects automatically discover their environment.
They exchange intentions rather than simple commands.
They negotiate possible actions.
They execute actions locally, without a systematic reliance on the cloud.
The architecture could utilise MQTT or CoAP as existing transport protocols, with a new layer of intelligence and negotiation on top.

No longer connecting objects to one another, but enabling them to spontaneously form a collective intelligence.
